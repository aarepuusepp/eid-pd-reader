# Browser integration documentation location

Browser integration is maintained by eid-pd-extension. Use its current
`docs/guides/APPLICATION-INTEGRATION-GUIDE.md` and `web-eid-pd/README.md`.
The reader [README](../../README.md) documents native installation/builds.
Applications bundle the SDK; no manual extension ID, injected script or webpage
PIN is part of the current flow. Existing legacy APIs share the same policy path.
