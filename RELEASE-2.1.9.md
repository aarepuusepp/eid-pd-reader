# EID-PD reader 2.1.9

Synchronize the native reader version with workstation package 2.1.9. The browser
extension remains independently versioned at 2.1.6. Card operations and dependency
versions are unchanged from reader 2.1.6, including the tested NFC CDOC2 workflow.
Versions 2.1.7 and 2.1.8 are intentionally skipped for the standalone reader to
align with the next workstation release without rewriting existing package tags.
